# 做题逻辑重构：顺序 / 随机 / 错题 / 收藏 / 模拟测试蓝图

- 状态：`ready-for-agent`
- 范围：练习抽题、模拟测试蓝图、学生字母类绑定、FSRS 间隔重复、错题清除、收藏/忽略

## Problem Statement

当前学生做题逻辑存在根本性问题：

1. 学生端暴露综合练习、知识点专项、顺序、随机、错题、模拟考试多个入口，但题量/知识点数量逻辑同时驱动练习模式与模拟测试，和“题量只服务模拟测试”的预期不符。
2. 顺序刷题、随机刷题仍然依赖 `LevelPracticeRule` / `KnowledgePracticeRule` 的题量配置，无法做到“顺序按题号全量刷、随机先未做后到期复习、不限数量”。
3. 学生没有“只能刷一个字母类题库”的绑定，所有有库存的字母类都会展示。
4. 错题/掌握度使用简单的“连续答对 3 次”模型，缺少间隔重复与难度建模。
5. 模拟测试 `ExamRule` 只有单选/多选总数，不能按知识点固定数量抽题，也不能配置多套试卷模板。
6. 缺少错题一键清除、收藏/忽略、独立收藏列表。

## Solution

把练习逻辑重构为四个学生入口 + 一个收藏列表：

- **顺序刷题**：当前字母类题库全部题目按题号递增，支持学习模式/练习模式切换；练习模式记 FSRS，学习模式只推进位置；记录上次位置和完整轮次 X。
- **随机刷题**：当前字母类题库全部题目，不限数量；抽题优先级为“未做优先 → 到期复习 → 低掌握/收藏补强”；全部达到“已掌握/复习间隔 ≥ 7 天”后提示阶段性完成。
- **错题模式**：当前字母类题库下未掌握错题全部进入，按 FSRS 到期/低掌握优先；支持一键清除错题（重置为新题，保留收藏/忽略）。
- **模拟测试**：使用“模拟测试蓝图”按知识点固定数量分层随机抽题；蓝图可多套命名、任意层级知识点、自动包含子级、禁止父子重叠；库存不足阻止开始。
- **收藏列表**：收藏的题目始终按 Hard 处理（答错仍按 Again），提供独立收藏列表页和“练习收藏题”入口；忽略题目按 Easy 处理，降低优先级但不隐藏。

所有学习状态按 **学生 × 字母类 × 题目** 隔离，使用统一 `StudentLevelQuestionState` 存储 FSRS、错题、收藏、忽略等状态。

## User Stories

1. 作为教师，我可以为每个学生指定一个可空的 `activeLevelId`，以便学生只能进入被指定的字母类题库；未分配的学生不能进入任何练习。
2. 作为教师，我可以随时把学生从 A 类改绑到 B 类，以便适应教学调整；改绑后旧字母类的进度保留但隐藏，改回时恢复。
3. 作为学生，我只能在教师指定的字母类题库内看到顺序、随机、错题、模拟测试和收藏列表，以便学习范围清晰。
4. 作为学生，我可以在顺序刷题中按题号从小到大连续刷题，以便系统化过一遍当前字母类题库。
5. 作为学生，我可以在顺序刷题中看到上次停留位置并继续，以便不重复从头开始。
6. 作为学生，我可以在顺序刷题中看到“本库顺序刷题完成 X 轮”，以便感知学习进度。
7. 作为学生，我可以在顺序刷题中切换“学习模式”和“练习模式”，以便第一遍看答案学习、后续认真作答。
8. 作为学生，在顺序刷题的学习模式下，我的答题不会污染 FSRS/错题统计，以便学习数据保持真实。
9. 作为学生，在顺序刷题的练习模式下，我的答题会正常计入 FSRS/错题/掌握度，以便系统了解我的真实水平。
10. 作为学生，我可以在随机刷题中优先遇到从未做过的题目，以便先完成覆盖。
11. 作为学生，当未做题目刷完后，我会进入到期复习，以便按间隔重复巩固。
12. 作为学生，当没有到期题目时，我会遇到低掌握或收藏题目，以便持续补强薄弱点。
13. 作为学生，当当前字母类所有题目都已掌握且复习间隔 ≥ 7 天时，我会看到“阶段性完成”的鼓励提示，以便知道该字母类已阶段性学完。
14. 作为学生，即使阶段性完成，我仍可以继续随机复习，以便考前保持手感。
15. 作为学生，我可以在错题模式中复习当前字母类下所有未掌握错题，以便集中攻克薄弱点。
16. 作为学生，错题模式不设每日上限，按 FSRS 到期/低掌握排序，以便优先复习最该复习的题。
17. 作为教师，我可以一键清除某个学生在当前字母类下的全部错题，以便重新开始该部分练习。
18. 作为教师/学生，清除错题前必须有二次确认，以便防止误操作。
19. 作为学生，清除错题后这些题目会变成新题，随机模式会重新视为未做，以便重新覆盖。
20. 作为学生，清除错题不会清除我的收藏/忽略标记，以便保留个人偏好。
21. 作为教师，每次清除错题都会记录审计日志，以便追溯操作。
22. 作为学生，我可以在练习题目上收藏题目，以便标记想重点复习的题。
23. 作为学生，收藏的题目始终按 Hard 处理（答错仍按 Again），以便更频繁出现。
24. 作为学生，我可以取消收藏，以便取消 Hard 状态。
25. 作为学生，我可以在练习题目上忽略题目，以便降低其出现频率。
26. 作为学生，忽略的题目不会被完全隐藏，只是优先级降低，以便以后仍可遇到。
27. 作为学生，我有一个独立“收藏列表”页面，以便集中查看和复习收藏题。
28. 作为学生，我可以从收藏列表发起“练习收藏题”，以便只刷收藏题。
29. 作为学生，在模拟测试中我看不到收藏/忽略按钮，以便考试不被干扰。
30. 作为学生，在模拟测试中答题后不会立即看到对错，交卷后统一看成绩和解析，以便模拟真实考试。
31. 作为教师，我可以为每个字母类创建多套命名模拟测试蓝图，以便准备不同难度/用途的试卷。
32. 作为教师，我可以在蓝图中选择任意层级知识点，并让它自动包含所有下级题目，以便灵活控制抽题粒度。
33. 作为教师，同一蓝图内不能选择有父子/祖先-后代关系的知识点，以便避免同一道题被重复抽到。
34. 作为教师，我可以为每个蓝图配置每个知识点的单选/多选数量、总时限（可空 = 不限时）和合格线，以便精确控制试卷结构。
35. 作为教师，当某个知识点/题型库存不足时，系统阻止开始并提示缺少数量，以便及时补题或调整蓝图。
36. 作为学生，模拟测试按蓝图分层均匀随机抽题，不采用错题优先/收藏加权，以便成绩具有代表性。
37. 作为学生，模拟测试的作答结果会计入 FSRS/掌握度，以便模拟测试同时也是有效学习数据。
38. 作为学生，我的 FSRS/错题/收藏/忽略状态按“学生 × 字母类 × 题目”隔离，以便不同字母类互不干扰。
39. 作为学生，顺序/随机/错题/收藏/模拟测试的作答都会更新同一份 `StudentLevelQuestionState`，以便状态一致。
40. 作为教师，旧的综合练习和知识点专项入口不再对学生展示，以便入口符合新的练习模型。
41. 作为学生，旧的综合练习/知识点专项历史记录仍可查看，以便不丢失历史数据。
42. 作为学生，今日复习入口暂时保留，但卡片生成改为基于 FSRS 状态，以便复习更科学。
43. 作为教师，规则配置页不再显示综合/知识点/顺序/随机的题量配置，只保留模拟测试蓝图管理，以便配置语义清晰。

## Implementation Decisions

### 领域语言

- 沿用 `字母类（Level）`、`知识点类型（KnowledgePointType）`、`分类号（category code）`、`知识点树（KnowledgePoint）`、`题型（SINGLE_CHOICE / MULTIPLE_CHOICE）` 等现有术语。
- “叶子知识点”不再作为蓝图唯一可选层级；蓝图允许任意层级，但抽题范围自动包含该知识点及其全部后代。

### 学生字母类绑定

- 在 `User` 上新增可空 `activeLevelId`，关联 `Level`。
- 未分配（`activeLevelId = null`）的学生不能创建任何练习会话，学生端显示“未分配题库，请联系老师”。
- 换绑不删除旧字母类进度；所有按 `levelId` 隔离的状态天然保留。

### 统一学习状态

- 新增 `StudentLevelQuestionState`，唯一键为 `(userId, levelId, questionId)`。
- 字段包含 FSRS 状态（state、dueAt、stability、difficulty、reps、lapses、intervalDays、lastReviewedAt）、人工标记（favorite、ignored）、统计（wrongCount、correctCount、lastResult）。
- `WrongQuestion` 不再作为主存储；错题列表从 `StudentLevelQuestionState` 派生（`wrongCount > 0` 且未掌握）。
- 旧 `WrongQuestion` 可保留为兼容视图，但新代码不再写它。

### 顺序刷题

- 题目范围：当前字母类下全部 ACTIVE 题目，按 `externalQuestionCode` / `sourceBankCode` 自然排序。
- 新增 `StudentLevelProgress`：`(userId, levelId)` 唯一，记录 `lastIndex` 和 `roundCount`。
- `PracticeSession` 新增 `learningMode Boolean @default(false)`；仅顺序模式使用。
- 学习模式不创建/更新 `StudentLevelQuestionState`，只推进 `lastIndex`；练习模式正常更新状态。
- 完整刷完一轮后 `roundCount += 1`。

### 随机刷题

- 不读取任何题量规则，不限制题目数量。
- 抽题优先级：
  1. 未做（`StudentLevelQuestionState` 不存在或 `reps = 0`）随机打乱；
  2. 到期复习（`dueAt <= now`），按 `favorite 优先 → dueAt 升序 → ignored 靠后`；
  3. 低掌握/收藏补强（`intervalDays < 7` 或 `favorite = true`）；
  4. 全部满足“已掌握/复习间隔 ≥ 7 天”时返回阶段性完成标记。
- 随机模式生成的会话包含当前优先级队列；后端不设题量上限，前端可分批展示。

### 错题模式

- 池子：当前字母类下 `wrongCount > 0` 且未掌握的题目。
- 排序：`favorite 优先 → dueAt 升序 → wrongCount 降序 → ignored 靠后`。
- 不设每日上限。

### 收藏 / 忽略

- `favorite = true` 的题目在练习类模式中优先级提高；正确作答映射为 FSRS `Hard`；答错仍为 `Again`；取消收藏后恢复普通 `Good` 映射。
- `ignored = true` 的题目优先级降低；正确作答映射为 FSRS `Easy`；答错仍为 `Again`；不隐藏题目。
- 收藏/忽略按钮出现在顺序、随机、错题、收藏练习中；不出现于模拟测试。
- 新增独立收藏列表页；支持“练习收藏题”会话，`PracticeMode` 新增 `FAVORITE`。
- 清除错题时保留收藏/忽略标记。

### FSRS 集成

- 引入 FSRS（建议 `ts-fsrs` 或内部等价实现）作为间隔重复核心。
- 答题映射：
  - 答错 → `Again`
  - 答对 + 收藏 → `Hard`
  - 答对 + 忽略 → `Easy`
  - 答对 + 普通 → `Good`
- 模拟测试不应用收藏/忽略映射，统一“答对=Good、答错=Again”。

### 模拟测试蓝图

- 新增 `ExamBlueprint` 与 `ExamBlueprintItem`。
- `ExamBlueprint`：`levelId`、`name`、`durationMinutes?`（空 = 不限时）、`passingCount`、`enabled`、`isDefault`。
- `ExamBlueprintItem`：`blueprintId`、`knowledgePointId`、`singleCount`、`multipleCount`。
- 旧 `ExamRule` 数据迁移为每个字母类的默认蓝图；`LevelPracticeRule` / `KnowledgePracticeRule` 不再控制练习模式题量，教师端隐藏。
- 蓝图校验：
  - 每个 item 的 `singleCount + multipleCount > 0`；
  - 同一蓝图内不允许选择有祖先/后代关系的知识点；
  - 每个 item 的库存必须满足：该知识点子树下 ACTIVE 题目中对应题型数量 ≥ 配置数量；
  - 不满足时阻止开始，并提示具体知识点、题型、缺少数量。
- 抽题：对每个 item，在“选中知识点子树 × 题型”范围内均匀随机抽取；所有 item 抽完后整体打乱顺序。
- 收藏/忽略不影响模拟测试抽题。

### 错题一键清除

- 默认仅教师可清除；可在设置中开放学生自助清除。
- 清除范围：当前字母类下全部未掌握错题。
- 清除效果：重置 `StudentLevelQuestionState` 为 `NEW`，清空 FSRS、`wrongCount`、`correctCount`、`dueAt`；保留 `favorite` / `ignored`。
- 每次清除写审计日志。

### 学生端 / 教师端

- 学生端只展示：顺序、随机、错题、模拟测试、收藏列表；隐藏综合练习和知识点专项入口，但历史记录保留。
- 顺序刷题页顶部有“学习模式 / 练习模式”开关，默认练习模式，切换不打断当前轮次。
- 教师学生管理页支持单个学生设置 `activeLevelId`。
- 教师规则页改为“模拟测试蓝图管理”：多套蓝图、复制/新建/删除、树形选择任意层级知识点、实时库存校验。

## Testing Decisions

### 测试原则

- 只测外部行为，不测实现细节。
- 抽题与状态转换优先放在纯领域函数中测试：输入题目列表/状态快照，断言输出题目集合/新状态，不依赖数据库。
- 服务层只做薄封装，集成测试覆盖会话创建、提交、续做、模拟交卷等关键链路。

### 主要测试缝

- **领域抽题引擎**（现有 `lib/domain/practice-engine.ts` 扩展或新增 `lib/domain/learning-engine.ts`）：测试顺序排序、随机优先级、错题池、收藏池、蓝图分层抽题、库存不足报错、FSRS 映射。
- **状态转换**（现有 `lib/domain/wrong-question-mastery.ts` 扩展或新增 FSRS 状态模块）：测试答错/答对/收藏/忽略/清除错题后的状态变化。
- **服务层集成**（现有 `lib/server/practice-service.ts` + `tests/integration/production-foundation.test.ts`）：测试学生绑定、创建会话、学习模式不记状态、练习模式记状态、模拟交卷后统一记状态、错题清除审计。
- **UI 组件**（现有 `tests/practice-runner.test.tsx` 等）：测试模式开关、收藏/忽略按钮、收藏列表、蓝图管理表单。

### 测试覆盖重点

- 随机刷题：未做优先、到期优先、低掌握补强、阶段性完成条件。
- 模拟蓝图：任意层级子树抽题、父子重叠校验、库存不足阻止、多套蓝图。
- FSRS 映射：普通/收藏/忽略/答错四种情况。
- 错题清除：重置为新题、保留收藏/忽略、审计日志。
- 学生绑定：未分配不可练、换绑后旧进度保留。

## Out of Scope

- 不改变题型支持范围：仍只支持单选题和多选题。
- 不新增多课程/多租户/班级批量绑定。
- 不迁移现有测试数据；旧 `WrongQuestion` 数据不迁入新表。
- 不做“提前结束模拟测试”的新交互；沿用现有 `ExamDraft` 草稿续做与放弃机制。
- 不做教师端的复杂班级/年级批量管理。
- 不实现自动解锁字母类；字母类只能由教师手动指定。
- 不实现收藏/忽略的教师端报表。
