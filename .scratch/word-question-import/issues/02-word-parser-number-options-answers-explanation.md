# 02 — Word 解析器：题号、选项、答案、解析与定位

**What to build:** Word 文本可被解析为逐题导入行：支持三种题号格式、不定项标注、A–H 选项、答案行与题干括号内答案、解析行合并，并自动跳过首个题号前的模板说明；每题带位置标签，题号与解析不写入题库。

**Blocked by:** 01 — 建立 .docx 文本抽取层

**Status:** completed

- [x] 支持 `1.`、`1、`、`（1）` 三种题号格式（兼容全角/半角括号），题号只用于定位，不写入题目编号。
- [x] 支持 `[不定项选择题]`、`[不定项选项题]`、`[不定项]` 三种标注，按答案个数沿用现有规则判定单选/多选。
- [x] 选项按顺序解析 A–H（系统上限），支持大小写并统一转大写，支持 `、`、`.` 等分隔写法。
- [x] 答案行非空可解析；无答案行时支持题干末尾括号内答案（如 `（A）`、`（A,C）`）并从中移除，空括号不匹配。
- [x] 解析行文本合并到该题解析，直到下一个字段标记或块尾；解析保留在批次行数据，不参与行校验与写库。
- [x] 首个题号之前的模板说明文字自动跳过，空行忽略。
- [x] 每题生成 `第 N 题` 位置标签，工作表名与题目编号留空；重复检测沿用无编号内容比对机制。
- [x] 单元测试覆盖三种题号、大小写选项、各类分隔符、答案行、括号内答案、解析行、三种不定项标注与模板说明跳过。

**验收证据：** 解析器实现与 `word-question-parser` 单测通过；提交 b7db318。
