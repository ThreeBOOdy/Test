# 03 — Word 解析器：不支持题型与整块报错

**What to build:** Word 中不支持的题型被清晰拒绝：判断题、填空题、简答/论述题逐题报错并带题号定位，材料题整块报错，超出系统上限的选项与缺答案、无题号文档等错误均给出可定位的提示，且不产生可入库的题目。

**Blocked by:** 02 — Word 解析器：题号、选项、答案、解析与定位

**Status:** completed

- [x] 无选项题目按顺序判定：答案为正确/错误/对/错 → 判断题报错；题干含 `（）` 且答案含 `|` 或 `；` → 填空题报错；其余 → 简答题报错，均带 `第 N 题` 位置。
- [x] 材料题从 `[材料题]` 到 `[材料题结束]`（或文档结束）整块报错并给出位置，块内行不拆成顶层题。
- [x] 选项超过 8 个时报错并说明系统上限。
- [x] 缺答案、文档中没有任何题号/题目均报错。
- [x] 单元测试覆盖判断题、填空题、简答题、材料题、选项超限、缺答案与无题号文档。
