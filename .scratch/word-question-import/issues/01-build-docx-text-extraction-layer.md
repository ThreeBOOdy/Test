# 01 — 建立 .docx 文本抽取层

**What to build:** 任意 `.docx` 文件可被解压并抽取为纯文本行，段落、换行与制表符被正确还原，媒体文件不读取，文本抽取层与后续媒体提取相互独立。

**Blocked by:** None — can start immediately

**Status:** completed

- [x] 将 jszip 从传递依赖升级为直接依赖，用于解压 `.docx`。
- [x] 从文档正文抽取文本：段落结束视为换行、文档内换行视为换行、制表符保留，其余 XML 标签忽略。
- [x] 不读取文档媒体文件；抽取层不依赖媒体内容，未来可独立扩展图片读取。
- [x] 用 jszip 在内存构造 `.docx` 夹具的单元测试覆盖段落、换行、制表符与忽略媒体。

**验收证据：** 抽取层实现与 `docx-text` 单测通过；提交 b1378a2。
