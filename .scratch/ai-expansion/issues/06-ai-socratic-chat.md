# 06 — AI 答疑教练（苏格拉底式）

**What to build:** 学生答错后可以“问 AI”，AI 结合本题、知识点、标准答案和该生历史错题，先给提示，学生继续追问后再给完整解析；支持流式输出和反馈。

**Blocked by:** 01、02

**Status:** pending

- [ ] 新增 `AiConversation` / `AiMessage` 模型（或 JSON 会话字段，推荐独立表）。
- [ ] 新增 `lib/server/ai/tutor.ts`：
  - 构造安全上下文：题目、选项、答案、知识点、该生本题/知识点统计。
  - 不包含任何个人敏感信息。
  - Prompt 明确“先提示，不要直接给答案”。
- [ ] 新增 `app/api/v1/ai/chat/route.ts`：
  - 支持 SSE 流式返回。
  - 校验学生身份。
  - 写入 `AiMessage` 和 `AiUsageLog`。
  - 做基础限流，例如每名学生每天最多 N 次。
- [ ] 新增学生端对话 UI：
  - 练习结果页“问 AI”按钮。
  - 对话面板，支持追问。
  - “有帮助 / 没帮助”反馈。
- [ ] 补充 API 测试（MockProvider）和组件测试。

**验收标准：**
- 学生答错后可发起 AI 对话。
- 首次回复以提示为主，不直接给完整答案。
- 追问后可获得完整解析。
- Prompt 中不包含身份证、手机号等个人信息。
- 调用有用量日志和审计。
