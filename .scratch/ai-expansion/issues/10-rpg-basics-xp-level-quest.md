# 10 — 轻度 RPG 基础：经验、等级、每日任务

**What to build:** 参考 Habitica，为学习行为增加经验值、等级和每日任务，让刷题和复习有成长感。

**Blocked by:** 07、09

**Status:** done

- [x] 新增 `PlayerProfile` / `PlayerLevel` / `QuestLog` 模型：
  - 经验值、等级、称号。
  - 每日任务：刷题、复习、错题清零、专注。
- [x] 新增经验值规则：
  - 完成一道题、完成一次复习、完成专注、错题清零等获得 XP。
- [x] 新增等级和称号：
  - 例如“见习报务员 → 熟练操作员 → 无线电专家”。
- [x] 新增 API：
  - 获取玩家状态。
  - 获取今日任务列表。
  - 完成任务后发放 XP。
- [x] 学生端 UI：
  - 首页显示经验条、等级、今日任务。
  - 任务完成后有轻量反馈。
- [x] 提供“关闭游戏化”开关（可在 12 号票统一接入设置）。

**验收标准：**
- 完成练习能获得 XP。
- 经验满后升级并更新称号。
- 每日任务能反映真实学习行为。
- 数据可留存、可统计。
