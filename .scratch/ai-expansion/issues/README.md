# AI 扩展分票（云 API 方案）

> 对应文档：`docs/ai-expansion-roadmap.md`
> 技术路线：服务器出网调用云 LLM API（OpenAI 兼容协议），客户端不连外网。
> 目标：把已确认的 AI 功能拆成可独立执行、可独立验收的开发分票。

## 阶段划分

| 阶段 | 分票 | 内容 |
| --- | --- | --- |
| M1 地基 | 01、02 | 模型网关 + 数据模型 |
| M1 解析与答疑 | 03、04、05、06 | AI 解析生成、教师审核、学生展示、AI 答疑 |
| M2 学习规划与报告 | 07、08 | 复习计划、学情报告 |
| M2 激励与游戏化 | 09、10、11 | 专注打卡、RPG 基础、知识点地图/副本 |
| M2 整合 | 12 | 开关、AI 结合、端到端验收 |

## 依赖关系

```text
01 模型网关
  └─ 02 数据模型
       ├─ 03 AI 解析批量生成
       │    └─ 04 教师审核
       │         └─ 05 学生端解析展示
       ├─ 06 AI 答疑
       ├─ 07 复习计划
       │    └─ 08 学情报告
       ├─ 09 专注打卡
       │    └─ 10 RPG 基础
       │         └─ 11 知识点地图/副本
       └─ 12 整合验收
```

## 执行建议

- 每张票必须可独立开发、独立测试、独立合入。
- 优先完成 01、02，后续票都依赖它们。
- 03~06 是 M1 核心，建议先跑通“解析 + 答疑”闭环。
- 07~11 是 M2 增强，可以在 M1 验收后开始。
- 每张票都要包含：What to build / Blocked by / Status / 任务清单 / 验收标准。
