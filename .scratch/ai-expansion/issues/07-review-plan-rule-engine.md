# 07 — 复习计划：数据模型与规则引擎

**What to build:** 基于错题、答题正确率和知识点薄弱度，生成“今日复习计划”和“考前冲刺计划”，先以规则引擎实现，后续可接 AI 增强。

**Blocked by:** 02

**Status:** done

- [ ] 新增 `ReviewPlan` / `ReviewCard` 模型：
  - 学生、日期、计划类型、状态。
  - 复习卡片关联题目、知识点、优先级。
- [ ] 新增 `lib/server/review-plan-service.ts`：
  - 从 `WrongQuestion` 取未掌握错题。
  - 从 `PracticeAnswer` 统计近期薄弱知识点。
  - 生成每日计划：优先未掌握错题 + 薄弱知识点专项题。
- [ ] 支持“考前冲刺”：根据考试日期倒排，生成每日题量。
- [ ] 新增学生端 API：
  - 获取今日计划。
  - 完成计划中的任务后更新状态。
- [ ] 学生首页或练习启动器展示“今日计划”。

**验收标准：**
- 学生能获取今日复习计划。
- 计划中的任务可点击进入对应练习。
- 完成后状态更新，第二天重新生成。
- 规则可离线运行，不依赖 AI。
