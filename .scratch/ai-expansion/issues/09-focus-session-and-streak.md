# 09 — 专注模式与连续打卡

**What to build:** 增加 Forest 式专注刷题模式：开始专注、完成目标、记录专注时长和连续打卡。

**Blocked by:** 02

**Status:** done

- [x] 新增 `FocusSession` 模型：
  - 学生、开始时间、目标时长/题量、实际时长、完成状态。
- [x] 新增 `StudyStreak` 或基于日期的 streak 计算逻辑：
  - 完成每日学习目标（刷题 / 复习 / 专注）即算打卡。
- [x] 新增 API：
  - 开始专注。
  - 结束专注并记录结果。
  - 获取当前 streak 和今日状态。
- [x] 学生首页展示专注入口、今日专注时长、连续打卡天数。
- [x] 补充服务层测试。

**验收标准：**
- 学生可以开始一次专注刷题并正常结束。
- 完成目标后 streak 增加。
- 中断或未完成不破坏连续记录。
