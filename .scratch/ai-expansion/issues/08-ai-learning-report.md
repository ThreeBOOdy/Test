# 08 — AI 学情诊断报告

**What to build:** 将现有统计服务输出转成自然语言报告：学生端周报、教师端班级薄弱点报告，用云 API 生成可读建议。

**Blocked by:** 01、02

**Status:** implemented（待验收）

- [x] 新增 `lib/server/ai/report.ts`：
  - 输入来自 `learning-statistics-service` 的结构化数据。
  - 生成学生周报：本周表现、薄弱点、下一步建议、鼓励。
  - 生成教师班级报告：全班薄弱知识点、建议课堂重点。
- [x] 新增 API：
  - 学生端获取本周报告。
  - 教师端获取班级报告。
- [x] 新增 UI：
  - 学生首页或历史页展示周报卡片。
  - 教师 reports 页展示班级报告。
- [x] 报告内容标注“AI 生成，仅供参考”。
- [x] 记录 `AiUsageLog`。

**验收标准：**
- 学生可查看本周 AI 学习报告。
- 教师可查看班级薄弱点报告。
- 报告基于真实统计数据，不包含个人信息。
