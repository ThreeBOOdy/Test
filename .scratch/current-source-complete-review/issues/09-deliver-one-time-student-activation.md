# 09 — 交付导入学生一次性激活流程

**What to build:** 管理员提交已通过预检的学生批次后，系统为每名学生生成只展示一次的初始密码和激活码；学生使用它们完成改密与人物选择，旧凭据无法再次使用。

**Blocked by:** 04 — 切换数据库有状态会话与密码策略；05 — 交付教师账号完整管理闭环；06 — 交付学生人物用户名注册流程；08 — 交付学生 Excel 导入预检。

**Status:** completed

- [x] 导入提交在单一事务中创建学生账号、凭据摘要和审计记录，任一行失败时整批回滚。
- [x] 初始密码和激活码只在成功结果中展示一次，数据库、日志和后续 API 均无法恢复原文。
- [x] 激活码默认 30 天过期、只能使用一次，并包含可使旧码失效的版本机制。
- [x] 学生必须同时验证初始密码和激活码，随后修改密码并选择人物身份，完成前不能进入练习功能。
- [x] 管理员重新生成凭据时旧激活码立即失效并产生审计记录；过期摘要按保留策略清理。
- [x] 激活重试、过期、遗失重置、并发使用和秘密不落库均有自动化测试。
