# 01 — 题目图片数据模型与读取接口

**What to build:** 题目级图片表建好，任意已登录用户可按图片 ID 获取图片二进制，响应带不可变长缓存；接口只暴露图片 ID 与二进制，不暴露内部存储细节，为后续切片提供图片读取地基。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 数据库迁移新增题目级图片表（图片 ID、二进制、格式、大小、内容哈希、所属题目与字段、排序），迁移与种子通过。
- [ ] 未登录访问图片接口被拒绝；任一已登录用户（学生或教师）可按图片 ID 获取图片，响应 Content-Type 正确。
- [ ] 图片响应带不可变长缓存头；不存在的图片 ID 返回 404。
- [ ] 集成测试覆盖登录/未登录、正确类型、404 与缓存头。
