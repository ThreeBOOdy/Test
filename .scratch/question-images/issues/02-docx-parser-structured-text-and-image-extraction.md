# 02 — Word 解析器升级：文本与图片联合抽取

**What to build:** 解析器从纯文本行升级为结构化段落模型，同一 `.docx` 同时产出文本行与「图片落在哪个字段」的位置引用；纯文本导入行为与升级前完全一致。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] `.docx` 解析能识别嵌入图片，并记录其所属段落及该段落当前归属的字段（题干或具体选项）。
- [ ] 答案行与解析行中的图片被忽略且不报错；孤立图片段落并入题干（与现有文本解析一致）。
- [ ] 现有纯文本 Word 导入的解析结果与升级前逐行一致（回归单测）。
- [ ] 用内存构造的含图 `.docx` 夹具覆盖题干图、选项图、答案行图、孤立段落图四种场景。
