# 05 — 提交含图题目与去重落库

**What to build:** 确认导入后图片从批次迁入题目级表，题干/选项文本写入图片标记；服务端复检与哈希去重生效；撤销批次只归档题目、不删图片，修订恢复不破图。

**Blocked by:** 01 — 题目图片数据模型与读取接口；04 — 含图 Word 预检链路（解析 → 入库 → 预览）

**Status:** ready-for-agent

- [ ] 提交时批次图片以同一 ID 迁入题目级表并删除批次副本；题干/选项文本含对应图片标记。
- [ ] 提交服务端复检复用预检规则（白名单/限额/归属）；含图批次重复判定按内容哈希：内容一致判完全重复/疑似，图片不同判冲突。
- [ ] 撤销导入批次只归档题目，题目图片仍可访问（供修订历史恢复引用）。
- [ ] 含图提交的集成测试覆盖迁移、去重与撤销；现有提交回归通过。
