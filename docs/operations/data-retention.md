# 临时数据每日清理

每天运行一次以下命令，并保留标准输出和非零退出码：

```powershell
.\scripts\data-retention.ps1
```

该任务按类别独立执行。一个类别失败不会阻止其他类别清理；失败类别会写入 `AuditLog`，并在下一次日常任务中重试。成功和失败审计均包含类别、阈值、保留期、持续时间、清理前数量、删除数量、剩余数量与错误信息（如适用）。

| 临时数据 | 保留规则 |
| --- | --- |
| 服务端会话 | 会话闲置或绝对到期后保留 30 天 |
| 学生一次性激活凭据 | 凭据到期后保留 7 天 |
| 学生导入预检 | `PREVIEW`、`FAILED` 或 `EXPIRED` 且到期后立即清理 |
| 教师题库导入预检 | `PREVIEW` 或 `FAILED` 且到期后立即清理 |
| 已结算或放弃考试的草稿 | 最后更新后保留 7 天 |

任务只删除临时实体及其级联的预检行。不得将题目、题目修订、练习或考试历史、错题进度、已提交导入批次或任何审计记录加入清理条件。若命令返回非零退出码，运维应检查 `AuditLog` 中的 `RETENTION_CLEANUP_FAILED` 事件并在修复后重跑命令。
