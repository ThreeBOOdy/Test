# 新功能实施计划

## 阶段 1：规格与回归边界

- 将设计规格固定在 `docs/feature-design.md`。
- 为统一启动参数、二级规则库存判断和多工作表行定位补充域层测试。

## 阶段 2：学生练习入口与纯净答题页

- 抽出统一练习启动器组件和 `app/student/practice/start/page.tsx`。
- 将学生首页入口改为指向启动器，继续练习仍直达已有 session。
- 保持 `PracticeRunner` 的服务端答案提交和快照恢复，收紧答题页布局为纯净训练界面。

## 阶段 3：二级知识点规则

- 复用现有 `KnowledgePracticeRule` 数据模型，补充末级知识点规则的域校验。
- 在规则编辑器按等级展示二级知识点分组，并在保存前按实际题型库存验证。
- 让启动器和学生首页使用同一可用规则计算逻辑。

## 阶段 4：多工作表导入

- 扩展 Excel 解析结果，保留 `sheetName` 和工作表内行号。
- 批次行序列化、预检展示、服务端提交和审计信息统一使用工作表定位。
- 保持旧单表输入兼容，并补充跨工作表重复题测试。

## 阶段 5：验证

- 运行新增域层与组件测试。
- 运行完整单元测试、lint 和生产构建；若环境依赖阻塞，记录准确失败原因。
