# 新功能设计规格

## 目标

在现有练习快照、服务端判题、教师规则配置和 Excel 预检导入基础上，补齐四项能力：

1. 学生纯净答题页：答题过程只保留题目、选项、进度、提交与导航，去除首页统计和教师侧信息；刷新、返回和继续练习不丢失快照。
2. 统一练习启动器：学生从一个启动入口选择综合、知识点、错题、顺序、随机和模拟考试，启动参数统一转换为服务端 session 创建请求。
3. 二级知识点规则配置：教师可以按“等级 + 二级知识点”配置单选、多选题数量，规则保存和学生入口展示都必须按末级知识点库存校验。
4. 保留教师侧 sheet 来源的 Excel 多工作表导入：上传文件时解析所有工作表，保留工作表名与来源行；预检、提交、重复判断和审计批次均使用同一份服务端快照。

## 交互与边界

### 学生纯净答题页

- `/student/practice?session=...` 是唯一答题视图；页面不渲染学生首页的统计卡片、练习入口和教师导航。
- 单选题只能保留一个草稿答案，多选题按题选项规格限制选择数量。
- 提交后立即显示正误与标准答案；最后一题提交后显示完成摘要，再由学生主动进入结果页或返回启动器。
- 练习状态全部以服务端快照为准，客户端只维护当前题号、草稿和展示状态目。

### 统一练习启动器

- `/student/practice/start` 负责展示入口；入口值使用 `mode`、`level`、`knowledge`、`session` 的统一约定。
- 入口只展示启用且库存足够的规则；服务端再次校验，不能通过客户端参数绕过规则。
- 已有进行中的练习优先提供“继续练习”，新建练习统一跳转到纯净答题页。

### 二级知识点规则

- 规则唯一键为 `levelId + knowledgePointId`，只允许末级知识点。
- 父级启用状态、等级启用状态、题目启用状态和题型库存都参与可用性判断。
- 停用父级知识点时，现有级联停用行为保持不变；学生入口不显示失效规则。

### Excel 多工作表导入

- 每个工作表第一行为表头，默认识别现有中文字段映射；空表或缺少必需表头产生工作表级错误。
- 每行快照增加 `sheetName`，行号为工作表内行号；展示与错误信息使用 `工作表名!行号` 定位。
- 同一文件中不同工作表的题目仍按现有唯一键去重；批次统计汇总所有工作表。
- 继续只允许客户端提交 `batchId`，正式写入前从服务端保存的批次行重新校验。

## 非目标

- 不改变题目判分规则、练习快照字段语义或现有登录与权限模型。
- 不迁移历史导入批次；旧批次按单工作表兼容读取。
- 不在本次增加题库编辑器的新字段。
