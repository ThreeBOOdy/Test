# 学生成长空间与纯净答题边界设计

## 背景

统一练习启动器上线后，公共首页把学生直接带到启动器。虽然学习首页、练习记录和错题本仍然存在，但学生进入系统后首先看到的只剩练习方式选择，容易误认为成长数据和错题功能已经被删除。

“纯净答题”只应描述具体答题会话，不应缩减学生学习空间的整体功能。

## 目标

- 公共首页的学生入口进入 `/student` 学习首页。
- 学习首页继续展示学习统计、最近训练、待巩固错题及全部训练入口。
- `/student/practice/start` 作为统一练习启动器，并保留学生侧桌面和移动导航。
- `/student/history` 继续承担学习记录和成长数据展示。
- `/student/wrong` 继续承担错题回顾、掌握状态和错题巩固入口。
- 只有 `/student/practice?session=...` 具体答题会话使用纯净布局，不显示常规学生导航，也不显示题型、等级和知识点元数据。
- 学习首页的统计卡片和记录区域保留稳定扩展位置，后续可增加积分、徽章和奖励模块。

## 信息架构

1. 公共首页 → 学生学习首页。
2. 学生学习首页 → 开始练习、练习记录、我的错题。
3. 开始练习 → 统一练习启动器。
4. 启动器选择训练路径 → 具体答题会话。
5. 具体答题会话退出 → 学生学习首页。

## 页面外壳规则

- `/student`、`/student/practice/start`、`/student/history`、`/student/wrong` 使用 `AppShell`，持续展示学习首页、开始练习、练习记录和我的错题导航。
- `/student/practice?session=...` 不使用 `AppShell`，让题干、选项、进度和题目导航成为唯一主要内容。
- 纯净答题页只展示中性标题“当前练习”或“模拟考试”，不展示等级、题型、知识点名称或分类号。

## 非目标

- 本次不创建虚假的积分、等级、徽章或奖励数据。
- 本次不重做已有历史记录和错题数据模型。
- 本次不改变教师端规则、题库或导入功能。

## 验收标准

- 未登录点击公共首页学生入口时，登录后的目标为 `/student`。
- 已登录学生点击公共首页学生入口时，直接进入 `/student`。
- 统一启动器显示学生导航，并可前往学习首页、练习记录和我的错题。
- 学习首页继续显示成长统计、最近训练和错题概览。
- 进入具体答题会话后看不到常规学生导航及题型、等级、知识点元数据。
