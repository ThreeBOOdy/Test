# Word 题库导入设计（仅选择题）

日期：2026-08-02

状态：已确认（图片导入设计已于 2026-08-05 补充确认，见第 12 节）

## 1. 背景与目标

题库目前只支持通过 Excel（`.xlsx`）批量导入题目。本次在保留 Excel 导入的同时，新增按“小鹅通 Word 批量导入模板”的格式导入 `.docx` 文件的能力，并复用现有的“预检 → 服务端批次 → 提交/撤销”流程。

## 2. 范围

### 2.1 本次支持

- `.docx` 文件，按小鹅通 Word 批量导入模板的格式说明解析。
- 仅接受选择题：单选题、多选题、不定项选择题（答案数 ≥2 判为多选题，=1 判为单选题，沿用现有 `inferQuestionType` 规则）。
- 自动跳过模板开头的“导入说明”文字（首个题号之前的内容），不强制教师先删除。
- 识别并校验“解析”字段，但不写入题库；解析内容保留在导入批次的行数据中供追溯。
- 兼容模板允许的“选择题答案写在题干末尾括号内”（如 `…（A）`）的写法。

### 2.2 本次不支持（导入时报错，不入库）

- 判断题（答案 `正确/错误/对/错`）：逐题报错。
- 填空题（题干含 `（）` 空位）：逐题报错。
- 简答/论述题（无选项）：逐题报错。
- 材料题（`[材料题]` … `[材料题结束]`）：整块报错；未来也不计划支持。
- 图片与公式：Word 中的图片/公式仅以图片形式存在，本次只抽取文本；**图片导入功能由后续单独对话新增**（见第 9 节）。

## 3. 来源格式（小鹅通 Word 批量导入模板）

模板“格式说明”与本题相关的规则：

- 所有题型必须有题号，支持 `1.`、`1、`、`（1）` 三种格式。
- 所有题型必须含“答案”字段且不能为空；选择题可在题目括号中直接填写答案。
- “解析”字段非必填。
- 选择题最多支持 A–Z 26 个选项，大小写均支持且需按顺序填写；选项与内容之间用 `、` 或 `.` 分开。
- 判断题答案仅支持“错误”“正确”或“错”“对”。
- 填空题仅支持用 `（）` 表示空；多个空答案用 `|` 分隔，一空多个答案用 `；` 分隔。
- 不定项选择题、材料题需在题号后用 `[不定项选项题]`、`[材料题]` 标注；材料题用 `[材料题结束]` 结束（示例文档实际写作 `[不定项选择题]`，两种写法均兼容）。

## 4. 解析规则

### 4.1 文本抽取

- 用 `jszip`（已是 `exceljs` 的传递依赖，升级为直接依赖）解压 `.docx`，读取 `word/document.xml`。
- 按段落抽取文本：`</w:p>` 视为换行、`<w:br/>` 视为换行、`<w:tab/>` 视为制表符；其余 XML 标签忽略。
- 图片媒体（`word/media/*`）本次不读取；抽取层与后续图片功能解耦，方便扩展。

### 4.2 预处理

- 删除首个题号之前的全部内容（覆盖模板说明文字未删除的情况）。
- 全文按行处理；空行忽略。

### 4.3 题号与题型标注

- 题号正则：`^\s*（(\d+)）` 或 `^\s*(\d+)[.、．]`（兼容全角/半角括号）。
- 题号只用于定位与报错（位置标签 `第 N 题`），不写入“题目编号”。
- 题号后紧跟 `[不定项选择题]`、`[不定项选项题]` 或 `[不定项]` 时按不定项处理（答案数决定单选/多选）。
- 题号后紧跟 `[材料题]` 时，整块（直到 `[材料题结束]` 或文档结束）报错“材料题暂不支持导入”，并输出该题位置。
- 所有满足题号正则的行都视为新题开始；`[材料题]` 内部的行不会拆成顶层题。

### 4.4 块内字段

- **答案行**：`答案[:：]` 开头，内容非空。
- **解析行**：`解析[:：]` 开头；其后的文本合并进解析，直到遇到新的字段标记（答案/选项/新题号）或块尾。
- **选项行**：`^([A-Za-z])[、.．:：\s]+内容`，且字母必须是当前下一个期望字母（A→B→…）；支持大小写，统一转为大写；最多 A–H（8 个，系统上限），第 9 个起报错“系统最多支持 8 个选项”。
- **题干**：块内其余行合并（保留换行），去除行尾空白。
- **括号内答案**：当块内没有答案行且存在选项时，若题干末尾是 `（…）`/`(…)` 且括号内只含选项字母与常见分隔符（如 `（A）`、`（A,C）`），提取为答案并从题干中移除；空括号（填空位）不匹配。

### 4.5 判断题/填空题/简答题识别（均报错）

按以下顺序判定无选项的题：

1. 答案 ∈ {正确, 错误, 对, 错} → 判断题，报错“判断题暂不支持导入”。
2. 题干含 `（）` 且答案含 `|` 或 `；` → 填空题，报错“填空题暂不支持导入”。
3. 其他无选项 → 简答/论述题，报错“简答题暂不支持导入”。

## 5. 数据映射

| Word 文档内容 | 去向 |
| --- | --- |
| 题号（`1.` / `1、` / `（1）`） | `locationLabel`（`第 N 题`），不入库 |
| 题干（含 `（）` 空位等文本） | `Question.stem` |
| 选项 A–H | `Question.options`（经现有选项编号规则） |
| 答案（`ABCD`、`A,B`、`A、B`、`A B`、小写、题干括号内） | `Question.correctOptionIds`（复用 `normalizeAnswer`） |
| 解析 | `ImportBatchRow.payload.explanation`，不写入 `Question` |
| 等级 / 分类号 / 知识点名称 | 页面表单整份应用 → `Question.levelId` / `knowledgePointId` |
| 图片 / 公式 | 本次不导入（另行规划） |

`ImportQuestionRow` 新增两个可选字段：

- `locationLabel?: string`：Word 行的位置标签（`第 N 题`）；`importRowLocation`、提交服务的 `formatImportLocation` 与预览界面优先使用它，Excel 行行为不变（`sheetName!rowNumber`）。
- `explanation?: string`：解析内容，随批次行载荷保存，不参与 `validateImportRow` 与写库。

Word 行 `sheetName` 留空，`externalQuestionCode` 留空（题号不入库；重复检测走现有“无编号疑似重复”内容比对机制）。

## 6. 等级与分类（已确认）

Word 文档不含等级/分类信息。上传 Word 文件时，页面显示：

- 等级（下拉，取已启用等级）；
- 分类号（必填，如 `4.1.1`）；
- 知识点名称（可选）。

以上值整份应用；等级或分类号缺失时预检直接报错。

## 7. 接口与页面改动

### 7.1 预检接口 `POST /api/v1/teacher/imports/preview`

- 按文件扩展名分流：`.xlsx` → 现有 ExcelJS 解析；`.docx` → Word 解析器。
- Word 分支要求表单字段 `levelCode`、`categoryCode`（`knowledgePointName` 可选），应用到所有解析行。
- 响应增加 `source: "EXCEL" | "WORD"`，供前端切换展示。
- 沿用 20MB 上限、5000 行上限、批内重复阻断、服务端复检。

### 7.2 页面与组件

- 同一导入页接受 `.xlsx` / `.docx`；选中 Word 时显示等级/分类号表单。
- 预览表格“来源”列优先展示 `locationLabel`（Word 显示 `第 N 题`，Excel 显示 `工作表!行号`）。
- 导航“Excel 导入”改名为“题库导入”，页面标题同步更新。

## 8. 校验、限制与错误

- 沿用现有：有效行/警告行/错误行统计，错误行存在时不能提交；提交时服务端重新校验。
- Word 特有错误：
  - 文件不是 `.docx` 或解析失败：整文件报错；
  - 文档中没有任何题号/题目：报错“未找到题目”；
  - 判断题、填空题、简答题：逐题报错并给出位置；
  - 材料题：整块报错并给出位置；
  - 选项超过 8 个：报错说明系统上限；
  - 缺等级/分类号：预检前报错。

## 9. 图片/公式导入（文本抽取阶段）

模板要求题目或选项中的图片、公式（仅以图片形式存在）嵌入文档。本次导入只抽取文本，不读取图片；图片导入设计已在后续访谈中确认（见第 12 节）。当前文本抽取层与媒体提取相互独立，可在不重写解析器的情况下补充图片读取与存储。

## 10. 测试

- 单元测试（vitest）：用 `jszip` 在内存构造 `.docx` 夹具，覆盖：
  - 三种题号格式、大小写选项、各类分隔符；
  - 答案行、题干括号内答案、解析行；
  - `[不定项选择题]` / `[不定项选项题]` / `[不定项]` 三种标注；
  - 判断题、填空题、简答题、材料题报错；
  - 选项超过 8 个、缺答案、缺等级/分类号、无题号文档；
  - 模板说明文字未删除时自动跳过。
- 现有 `question-import` 单测与导入 e2e 保持不回归。

## 12. 图片/公式导入设计（已确认）

日期：2026-08-05（grill-with-docs / domain-modeling 访谈确认，无补充）

### 12.1 范围

- 图片可出现在题干或选项中，每处可有多张；公式（仅以图片形式存在）与普通图片一视同仁。
- 图片导入仅支持 Word（`.docx`）来源；Excel 工作簿检测到任何图片时整份拒绝，提示改用 Word 模板。

### 12.2 内容表示

- `stem` 与 `option.text` 仍为字符串，图片位置内嵌标记 `[图:qimg_xxx]`，`qimg_xxx` 是图片记录 ID；标记顺序即文档内顺序。
- 预检期与提交后标记不变：同一图片 ID 从批次级表迁入题目级表，内容字符串无需改写。
- 渲染层统一按标记拆分文字段与图片段；教师手动编辑 v1 不支持增删图片，编辑框中标记原样显示、保存时保留。

### 12.3 存储与生命周期

- 预检期：图片提取后写入批次级表（batchId、行号、所属字段、图片 ID、二进制、哈希、格式、大小），预检页可预览。
- 提交期：同 ID 迁入题目级表（questionId、所属字段、排序、二进制、哈希），并删除批次副本。
- 撤销导入批次只归档题目，不删图片；图片永不物理删除（修订快照可能引用），无垃圾回收。
- 过期未提交的批次图片留存，与现有批次数据不清理的行为一致。

### 12.4 格式与限额

- 白名单：PNG / JPEG / GIF / WebP；EMF / WMF / TIFF / BMP 等逐题报错，提示“将该图片/公式另存为 PNG 或 JPG 后重新插入”。
- 单张图片 ≤5MB；每题最多 10 张，超出该题报错。
- 文件 20MB、请求体 21MB、单批 5000 题上限维持不变。

### 12.5 解析与归属

- 图片按所在段落当前的字段归属：题干段落 → 题干；选项行 → 该选项；答案行/解析行的图片忽略、不报错；孤立图片段落并入题干（与现有文本解析一致）。
- 预检页对含图行显示图片数量并缩略渲染，供教师核对归属。

### 12.6 去重与访问

- 去重比对时把图片标记按图片内容哈希归一化：同一图片字节内容无论 ID 如何都视为相同，字节不同才视为内容不同。
- 新增鉴权图片接口按 ID 输出二进制，响应带 immutable 长缓存；任一已登录用户可取题目图片，批次图片仅教师可取。

### 12.7 已确认决策记录

| 决策 | 结论 |
| --- | --- |
| 图片位置 | 题干+选项，可多张；公式图同待遇 |
| 内容表示 | 字符串内嵌标记 `[图:qimg_xxx]` |
| 存储 | MySQL 专用表；预检批次级 → 提交题目级 |
| 生命周期 | 图片永不物理删除；撤销只归档题目 |
| 格式 | 仅 PNG/JPEG/GIF/WebP；其余逐题报错提示转换 |
| 限额 | 单图 ≤5MB、每题 ≤10 张；文件/请求体/题量上限不变 |
| 归属 | 按文本流当前字段；答案/解析行图片忽略 |
| 去重 | 图片按内容哈希归一化后比对 |
| 访问 | 登录即可取题图；批次图仅教师；immutable 缓存 |
| 渲染 | 共享组件覆盖全部渲染面；练习端点击放大；手动编辑 v1 不支持图片 |
| Excel | 含图整份拒绝 |
