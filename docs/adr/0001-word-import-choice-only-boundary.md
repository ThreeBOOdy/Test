# Word 题库导入仅接受选择题

题库系统当前只支持 `SINGLE_CHOICE` 与 `MULTIPLE_CHOICE` 两种题型（见既有设计文档的题型边界）。小鹅通 Word 批量导入模板包含判断题、填空题、简答题与材料题，但 Word 导入明确只接受选择题：判断题不转换为“正确/错误”二选一，填空题、简答题、材料题一律报错不入库。保持题型边界避免了对练习抽题、学生作答、判分与题目编辑的全栈扩展；未来如需新题型，应先作为独立功能扩展数据模型，再放开对应导入。

## Considered Options

- 扩展数据模型新增判断题、填空题、简答题、材料题：改动全栈且超出导入范围，未选择。
- 判断题转换为“A.正确 / B.错误”二选一选择题：保持模型不变但改变了题目语义，且用户明确排除，未选择。
- 仅接受选择题（选定）：导入链路内完成，可随时回退。
