# 题目图片以文本标记内嵌、二进制存 MySQL

题目图片功能把题干/选项从纯文本扩展为「文本 + 图片标记」：内容仍以字符串保存，图片位置用 `[图:qimg_xxx]` 标记，渲染时拆分为文字段与图片段；图片二进制存 MySQL（预检期存批次级表，提交后存题目级表），经鉴权接口按 ID 输出。选择数据库而非磁盘卷或对象存储，是因为生产部署只有 MySQL 数据卷能跨容器重建持久化，且局域网离线环境无对象存储；选择文本标记而非 HTML 富文本，是为了保持现有纯文本题目与全链路的字符串处理不变，避免 XSS 与渲染迁移成本。

## Considered Options

- HTML 富文本：渲染灵活但有 XSS 风险，现有渲染面全部要迁移，未选择。
- 结构化分段数组：类型最干净，但数据库列、JSON、校验、去重与所有组件形状全变，破坏性最大，未选择。
- 磁盘卷 + 静态文件服务：需改 docker-compose 与备份方案，并处理孤儿文件，未选择。
- 对象存储：局域网离线环境不可用，未选择。
